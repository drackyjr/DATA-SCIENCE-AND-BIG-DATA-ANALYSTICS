### 📘 **DSBDA Assignment Series Overview**

**Repository:** [drackyjr/dsb](https://github.com/drackyjr/dsb/)

**Objective:**
This series of assignments is designed to provide hands-on experience with data science concepts, including data preprocessing, exploratory data analysis (EDA), machine learning model implementation, and big data tools. Each assignment focuses on practical applications using Python and Jupyter Notebooks.

---

### 🗂️ **Assignment Breakdown**

1. **Assignment 1: Introduction to Data Science**

   * Overview of data science lifecycle.
   * Basic Python operations and data structures.

2. **Assignment 2: Data Preprocessing**

   * Handling missing values, encoding categorical variables.
   * Normalization and standardization techniques.

3. **Assignment 3: Exploratory Data Analysis (EDA)**

   * Descriptive statistics.
   * Data visualization using Matplotlib and Seaborn.

4. **Assignment 4: Data Wrangling**

   * Merging, grouping, and reshaping datasets.
   * Data cleaning techniques.

5. **Assignment 5: Introduction to Machine Learning**

   * Implementing simple linear regression.
   * Evaluating model performance.

6. **Assignment 6: Classification Algorithms**

   * Logistic regression, decision trees.
   * Confusion matrix and ROC curves.

7. **Assignment 7: Clustering Techniques**

   * K-means clustering.
   * Silhouette analysis.

8. **Assignment 8: Dimensionality Reduction**

   * Principal Component Analysis (PCA).
   * Feature selection methods.

9. **Assignment 9: Introduction to Big Data Tools**

   * Basics of Hadoop and MapReduce.
   * Introduction to Apache Spark.

10. **Assignment 10: Capstone Project**

    * End-to-end data science project.
    * Problem statement, data collection, preprocessing, model building, and evaluation.

---

### 🛠️ **Tools and Technologies Used**

* **Programming Language:** Python
* **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn
* **Big Data Tools:** Hadoop, Apache Spark
* **Environment:** Jupyter Notebook
